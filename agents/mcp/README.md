# QuotaPot MCP server

MCP server for WorkBuddy, Claude Desktop, ZCode and Codex.

Tools: `quotapot_status`, `quotapot_balance`, `quotapot_cursor_usage`, `quotapot_codex_usage`, `quotapot_usage_models`.

Install from the repository (no npm account needed):

```sh
npx -y --package github:Caffrey-Li/dsh-bot-QuotaPot#v0.4.0 quotapot-mcp
```

For a local clone:

```sh
node /ABSOLUTE/PATH/TO/dsh-bot-QuotaPot/agents/mcp/server.cjs
```

See `../templates/` for host configs and `../README.md` for the full matrix.
